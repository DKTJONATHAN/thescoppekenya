# Za Ndani UI

Dark-only blackout. Canvas near-black. Accent orange `#e85d04`. Playfair headlines. Inter UI. One accent — no rainbow category chips.

Keep ticker, masthead, split hero, live TV strip, live updates rail.
Add county shelf and sticky mobile article bar.
LCP is the hero image. Keep wsrv.nl preconnect first. Ads stay deferred.
Clock says EAT. Live TV copy stays Watch live Kenyan TV.

## Article page

- Headline, dek, byline, EAT timestamp, share row
- Hero image with caption
- 65–72 character line length on desktop
- Sticky mini-bar on mobile (section + share + live TV)
- “What we know” is a numbered blackout brief **only on hard news** (News / Politics / Business). Never on opinion, lifestyle, gossip, showbiz, sports match reports, or why/how explainers. If the markdown has a junk box, strip it in the template.
- Related stories from same desk, not random tags

## Interior pages

News, Entertainment, Sports, Business, Lifestyle, Live, Hubs, Authors, Ethics, Corrections, Contact, About share the same chrome: 3px orange rule, serif display title, muted dek, hairline cards. No rounded-3xl SaaS panels. No rose/cyan/purple tickers.
